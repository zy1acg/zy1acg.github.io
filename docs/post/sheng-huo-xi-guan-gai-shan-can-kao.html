现在面临的问题

  1. 酒精：酒精会抑制肝脏糖异生，空腹熬夜饮酒后，容易引起低血糖。
  2. 一天只吃一顿、空腹时间过长：肝糖原储备被耗尽后血糖容易掉下来。
  3. 体重偏瘦、肌肉少、糖原储备库不足：肌肉是天然的糖原仓库，老师人瘦+肌肉少，存储糖原的能力弱，对长时间空腹更敏感。

吃

分餐

  • 估算了一下：老师这个身高体重，每天维持需要 1600 大卡左右，你现在饮食大概是不足热量的。所以需要补上一些，而不是再减体重了。你要做的是有持续可供的血糖，而不是一味的追求瘦。
时间 搭配公式 示例
15:00 醒后（如果能早醒） 半份主食 + 一份蛋白质（肉、蛋） + 一份蔬菜 补充能量，别让身体继续分解蛋白质供能
18:30 直播开工前 一份主食 + 一份蛋白质（禽肉，鱼肉、瘦牛肉，瘦猪肉）+一份蔬菜 吃了再直播
22:00 直播中加餐 一杯无糖酸奶或牛奶 + 一小把原味坚果 如果提早下播，或者不饿，就不吃

外卖 / 堂食点菜规则（不会做饭也能执行）

点餐公式： 主食 + 蛋白 + 蔬菜。

  • 配菜优先选：白切鸡、去皮卤鸡腿、清蒸鱼、虾、瘦牛肉、瘦猪肉、豆腐、鸡蛋、番茄炒蛋、清炒时蔬、凉拌菜（少辣油）。
  • 主食选：米饭、杂粮饭、整个红薯、整个玉米，整个土豆等加工少的原型食材主食；不要一餐只有炒饭、炒面、油炸面点。
  • 少选：油炸类、红烧浓油赤酱、烧烤、奶油浓汤、含糖奶茶和甜品（每周最多 1–2 次）。
  • 小技巧：汤汁酱料少拌饭；饮料换无糖茶、无糖豆浆、白水；过咸的菜配水或淡茶。
  • 便利店应急备选：茶叶蛋、无糖纯牛奶、无糖酸奶、无糖豆浆、香蕉、小包装无糖坚果。

饮食的注意点

  • 绝对不要空腹喝酒：喝酒前先吃菜+主食。
  • 饮酒过程中每杯酒穿插一杯水或无酒精饮品。
  • 酒精疑似是目前低血糖风险里很关键的一环：熬夜 + 空腹 + 饮酒的组合最容易出问题。
  • 零食注意限量吃，因为很多零食的脂肪含量不少。

睡

  • 老师的作息属于"白天睡眠、夜间工作"的夜班型。完全调整回白天工作并不现实，目标是：把不规律的入睡时间，变成规律。 好的情况是，老师的睡眠时间有保障。

  • 尽量每日入睡时间不要相差太大。

  • 别在睡前喝酒。它让人睡得快，但后半夜容易醒。

动

  • 每周两到三次、做做自重训练：深蹲、靠墙俯卧撑、臀桥等等，教程可以搜抖音看看。
  • 特别说一下为什么建议老师练点肌肉：老师偏轻，肌肉是血糖的缓冲垫。同样掉一点血糖，有肌肉的人没感觉，因为有肌肉内的糖原储备，没肌肉的人就直接发虚了。老师的肌肉含量，别人刷100个嘉年华都换不来的。

多晒太阳

  • 老师宅家里的时间居多，多到户外晒太阳，可以促进人体合成维生素D，维生素D对人体内分泌有至关重要的作用，对改善心情和压力也有积极效果。老师以后溜嘉年华的时候可以出去多晒晒太阳。注意晒太阳不要隔着玻璃和涂防晒霜，春夏的季节在户外晒太阳的时候尽量裸露皮肤。
