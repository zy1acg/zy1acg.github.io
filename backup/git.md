### git初始化
```bash
git config --global user.name "yourname"
git config --global user.email "youremail"
git config --global core.editor vscode
```
+ name commit提交信息中，别人认识你，协作情况下使用。
+ email 个人联系信息，与github无关
+ editor git提交的时候默认打开的编辑器
