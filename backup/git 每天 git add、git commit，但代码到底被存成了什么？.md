## git 中代码到底被存成了什么？

你每天 git add、git commit，但你的代码到底被存成了什么？很多人以为 Git 存的是"每次改了哪几行"，像一摞补丁层层叠上去——其实不是。

建一个只放 hello.txt 的仓库、提交一次，.git/objects 里正好多出三个对象。
- 顺着 commit 往里扒——commit 里没有代码，只指向一个 tree；
- tree 是目录表，记着"哪个文件对应哪块内容"，指向 blob；
- blob 才真正装着文件内容。commit→tree→blob，这就是 Git 存东西的骨架。

最妙的是：
这些 SHA 不是随机编号，是**按内容算出来的**。我们手动对 "blob 长度\0内容" 取 sha1，结果和 Git 里的 SHA 逐字一致——这叫内容寻址，内容决定地址。
懂了它，三件事就顺理成章：相同内容自动去重、对象不可变、提交靠 parent 串成链。
回头再看 reset/reflog 为什么"删了能找回"，全通了。
